Your Portfolio Editor

Edit the words, add your pictures, then download one updated file. This is a local editing tool, not a password-protected admin page. Nothing is sent to a server, and changes do not automatically appear on a live website.

Your pictures

Upload JPG, PNG or WebP (maximum 8 MB per image). The editor resizes large images to 1600 pixels and embeds a copy in your exported file, so no separate picture upload is needed. Keep originals backed up. Add a brief image description for screen-reader users.

Continue or start over

To continue a previous editing session, select the content.js you exported. Imports only read JSON data; uploaded JavaScript is never executed. Your current edits stay in this tab until you export them. Always keep a backup.

Reset returns to the content.js that was loaded when this editor opened; it does not change files on your computer.

After exporting

Find the downloaded file (usually in Downloads). Rename it exactly content.js, then move it into your portfolio folder, replacing the old file. Refresh index.html to see the changes. If your site is online, upload the updated website folder again. See publishing instructions.

The preview is only for this session. If your browser blocks local preview storage, export and replace the file instead.
